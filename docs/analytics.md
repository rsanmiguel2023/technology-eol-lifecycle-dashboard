# Analytics Framework

This project evaluates technology end-of-life exposure in a synthetic Canadian banking environment using executive-oriented analytics. The analytical framework connects asset lifecycle status, business unit ownership, vulnerabilities, software compliance, refresh budgets, and incident downtime.

## Primary Questions
1. Which assets are already past EOL?
2. Which business units have the highest EOL exposure?
3. Which unsupported assets also have critical vulnerabilities?
4. How much budget is needed for refresh planning?
5. Which software versions create the largest compliance risk?
6. How does EOL status relate to incidents and downtime?

## Executive Use
The dashboard is designed for CIO, CTO, Infrastructure, Risk, Compliance, and Finance audiences. Each page presents a question, finding, interpretation, and recommendation before showing detailed data.
