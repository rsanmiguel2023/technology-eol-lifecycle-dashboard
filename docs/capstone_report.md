# Technology EOL Lifecycle Management Dashboard Report

## Background
Large banks operate thousands of endpoints, servers, network devices, and software installations. When hardware or software passes vendor support dates, operational, security, compliance, and cost risks increase.

## Purpose
The purpose of this project is to create a portfolio-ready Technology EOL analytics solution that mirrors the work of a Senior Analyst responsible for lifecycle governance, risk reporting, and refresh planning.

## Scope
The project covers workstation/laptop assets, servers, network devices, cloud resources, software installations, vulnerabilities, incidents, and refresh budget planning.
