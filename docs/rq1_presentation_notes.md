# RQ1: Assets Already Past EOL — Presentation Notes

Open with the research question: Which assets are already past End of Life?

Plain-English message: The first executive priority is to identify assets that have already passed vendor support. These assets should be treated as active risk items, not ordinary inventory records.

Recommended management action: Create a Past EOL remediation queue. Prioritize critical assets, assets with vulnerabilities, and assets with incident history before lower-risk refresh candidates.
