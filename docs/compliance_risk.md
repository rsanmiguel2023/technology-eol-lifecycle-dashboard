# Compliance Risk

## Business Question

Which software versions create the highest compliance exposure?

## Key Findings

- Unsupported software installations identified: **91,618**.
- The largest unsupported software drivers include **Adobe Acrobat Pro 2020, Google Chrome, Microsoft Teams Classic, Windows 10 Enterprise, OneDrive**.
- Unsupported browsers, collaboration tools, productivity software, operating systems, and developer tools all contribute to the compliance footprint.

## Interpretation

Unsupported software is a governance issue because it may no longer receive vendor security updates or support. Even when business operations continue normally, unsupported software can increase audit exposure and reduce control effectiveness.

## Business Impact

Software remediation may provide a faster compliance-risk reduction path than full hardware replacement. Prioritizing widely installed unsupported software can reduce exposure across thousands of assets quickly.
