# Data Dictionary

## Core Fields
- Asset_ID: Unique hardware or infrastructure asset identifier.
- Asset_Type: Laptop, Desktop, Server, Switch, Router, Firewall, Wireless Access Point, or Cloud Resource.
- Business_Unit: Owning department.
- Lifecycle_Status: EOL timing bucket.
- Replacement_Cost_CAD: Estimated replacement cost.
- Critical_Vuln_Count: Count of critical vulnerabilities linked to the asset.
- Total_Downtime_Hours: Incident downtime linked to the asset.
- Risk_Score: Composite risk score combining lifecycle, criticality, vulnerabilities, incidents, and cost.
- Risk_Band: Executive risk category.
