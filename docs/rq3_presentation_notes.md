# RQ3: Unsupported Assets with Critical Vulnerabilities — Presentation Notes

Open with the research question: Which unsupported assets also have critical vulnerabilities?

Plain-English message: The highest-risk lifecycle scenario is the overlap between unsupported technology and critical vulnerabilities. These assets create security and audit exposure and should be prioritized ahead of ordinary refresh items.

Recommended management action: Create an emergency remediation track for Past EOL plus critical vulnerability assets. Options include patch, isolate, replace, decommission, or formally accept risk.
