# Executive Summary

The Technology EOL dashboard shows where unsupported assets exist, which business units carry the highest exposure, which unsupported assets also have critical vulnerabilities, how much budget is needed for refresh planning, which software versions create compliance risk, and how EOL status relates to incidents and downtime.

## Management Message
The organization should prioritize high-criticality unsupported assets, especially where EOL status overlaps with critical vulnerabilities, business-critical applications, and recurring incidents.
