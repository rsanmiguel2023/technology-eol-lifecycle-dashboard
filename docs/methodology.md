# Methodology

1. Ingest raw source-system extracts.
2. Run data quality checks.
3. Profile raw data with EDA.
4. Clean and standardize operational data into `data/processed`.
5. Engineer lifecycle, risk, compliance, budget, and operational features into `data/engineered`.
6. Generate executive reports, figures, and Power BI datasets.
7. Present findings in Streamlit and Power BI.
