# RQ5: Software Compliance Risk — Presentation Notes

Open with the research question: Which software versions create the largest compliance risk?

Plain-English message: Unsupported software versions can trigger audit findings and security exceptions. This page identifies software versions with the largest unsupported installation footprint.

Recommended management action: Create a software remediation backlog. Prioritize unsupported operating systems, databases, Java, Python, Node.js, browsers, and security tools.
