# Data Description

The dataset is synthetic but uses real vendor, product, hardware, software, cloud, and network technology names. Internal asset IDs, location records, incidents, vulnerabilities, refresh plans, and costs are simulated for portfolio use.

## Main Tables
- hardware_assets.csv
- software_catalog.csv
- software_installations.csv
- technology_lifecycle_catalog.csv
- vulnerabilities.csv
- incidents.csv
- refresh_projects.csv
- budget_costs.csv
- cloud_resources.csv
- locations.csv
